# UI redesign and Browser audit

This records the initial redesign pass. A later user review exposed journey-marker and camera collisions beyond these checks; see the [continuing interface audit](./ui-polish-follow-up-2026-10-19.md) for the follow-up work and its current verification scope.

The interface was rebuilt locally as a contemporary field atlas. The app remains a static Vite application with vanilla JavaScript and CSS. Imported dataset records, ancient IDs, and provider endpoints are preserved. MapLibre was updated to 6.15.0 to resolve its third-party-attribution sanitizer advisory; compatible PostCSS, nanoid, and source-map-js updates also clear the dependency audit. Axe-core is a development-only addition.

## Design and interaction

- A light paper surface, forest ink, and clay accents replace the previous dark, layered styling. Newsreader provides the editorial hierarchy; locally hosted Source Sans 3 handles controls and reading text.
- Place identity, verse-reference totals, and book totals lead the reading panel. Overview, References, and Location separate the main tasks. Technical identification and scoring details use disclosures.
- Desktop search results occupy the reading column alongside the map. Mobile uses a selected-place dock and full reading sheets. Native book selectors show full names and counts.
- Twenty-one places have brief biblical-context introductions with passage links. These are kept separately from the imported records; validation checks each reference belongs to the intended ancient-place ID.
- Empty searches offer explicit spelling suggestions for close place-name mistakes. Selecting one preserves the current filters. Desktop uses the persistent header search; the mobile results dialog has its own search field.
- Nearby map points group at regional and city scales. Selected places retain their name; records sharing an exact coordinate open a chooser at close range. Journey lines have a light outline for visibility over satellite imagery.
- Selected groups draw above neighboring groups and retain their clay highlight. A new search exits the shared-coordinate chooser. Ordinary desktop wheel scrolling zooms the full-workspace map without a modifier key.
- Journey navigation stays within the visible stops of the active journey. Filtered stops are identified in the itinerary, and an empty journey offers a direct reset action.
- Reference links open the ESV on Bible Gateway. Reference search handles full names, abbreviations, compact references, exact chapters, and chapter/verse boundaries. Loading more references preserves book disclosures and moves keyboard focus to the newly available content.
- Keyboard focus stays inside mobile dialogs. The map supports arrow-key panning, plus/minus zoom, `0` to fit the current places, and Enter to open the place list. Focus outlines, reduced-motion rules, and forced-colors fallbacks remain in the stylesheet.
- Map and data failures provide a retry action. A basemap retry preserves the loaded data, reading state, and disclosures. A slower load is described as pending, and the recovery card includes a direct place-list action.
- Recovery actions remain visible on a 320×480 phone and a 568×320 landscape viewport. The pending message appears after 12 seconds while the map continues loading.
- The mapping renderer loads in a separate chunk alongside the place data. Its named imports and self-contained worker follow MapLibre's Vite setup. Main UI code is roughly 120 kB; the renderer is about 1,048 kB (285 kB gzip), with a separate 517 kB worker (147 kB gzip).
- The browser and home-screen icons now use the same folded-map mark as the header. The maskable icon keeps the mark within its safe area.
- Nginx compresses JSON, scripts, and styles, caches fingerprinted assets immutably, and revalidates stable filenames. Manifest responses use `application/manifest+json`.

The final `npm run check` passed all 23 tests, including three reference-search tests and three spelling-suggestion tests. Data validation covers 1,309 resolved places, 10 routes, and editorial passage links. A fresh `npm ci` passed with zero reported vulnerabilities. The audit tool and axe-core are absent from production assets. Final desktop scans of the overview, expanded location disclosures, expanded journey itinerary, and scrollable map key each had zero automatic violations. Responsive boundaries were rechecked after the final changes at 320×480, 568×320, 760×900, 761×900, and 1180×820, with no page overflow.

## Remaining practical checks

Physical iOS/Android keyboards, browser zoom/chrome and safe areas, screen-reader behavior, and Windows forced-colors rendering still need device testing. Third-party tile availability remains a runtime dependency. Docker's daemon was not running, so the container image itself was not built locally; its Nginx rules were exercised in the temporary native server. This work is local; it has not been committed, pushed, or deployed.
